# Отложенный порт фич omp/omo (для сильных моделей)

Список крупных фич, которые мы сознательно НЕ портируем сейчас (сложность/объём/риски). Это
заготовка-задание для более сильных моделей или отдельного этапа. Для каждой фичи: суть, где
исходники, что нужно для порта в DSH, оценка сложности.

## 1. dsh-lsp — символьная навигация по коду

- Суть omp: `lsp`-тул — rename, references, definition, code actions, diagnostics; позиционные
  операции (`file` + `line` + `symbol`), `apply:false` для превью.
- Исходники: `/nix/store/.../omp-17.3.4/share/omp/src/lsp/` (20 файлов) + `prompts/tools/lsp.md`,
  `lsp-late-diagnostic.md`; пример интеграции — `src/tools/lsp.ts`.
- Порт в DSH: server-плагин `dsh-lsp` с клиентом LSP (stdio), пул серверов по языкам, тулы `lsp_*`.
  Это самый большой пробел DSH (нет LSP вообще).
- Сложность: 🔴 высокая (LSP-протокол, жизненный цикл серверов, маппинг позиций).

## 2. dsh-eval — персистентное ядро (Python/Bun)

- Суть omp: `eval`-тул — постоянное ядро: состояние живёт между вызовами и субагентами;
  инкрементальные ячейки (imports → define → test → use), `parallel(thunks)` внутри ячейки, reset
  при крахе ядра.
- Исходники: `src/eval/` (20 файлов: kernel-base, executor-base, backend, budget/concurrency/
  idle-timeout-bridge) + `prompts/tools/eval.md`.
- Порт в DSH: `dsh-eval` — долгоживущие python/bun-процессы за плагином. Отличие от run_code:
  состояние между вызовами. Сложность: 🔴 высокая (управление ядрами, изоляция, бюджеты).

## 3. checkpoint / rewind — откат контекста разведки

- Суть omp: `checkpoint` ставит точку перед разведкой; `rewind` откатывает контекст к точке, заменяя
  промежуточные вызовы кратким отчётом (экономия токенов при длинных расследованиях).
- Исходники: `prompts/tools/checkpoint.md`, `rewind.md`.
- Порт в DSH: контекст-хирургия — тяжело (нужен контроль над историей сессии).
- Сложность: 🔴 высокая (меняет модель контекста DSH).

## 4. TTSR / hindsight runtime

- Суть omp: «машина времени» — regex-правила на стриме выводов агента прерывают поток и инжектят
  коррекцию (условие/scope/body); плюс mental-models — фоновые сводки в промпте.
- Исходники: `src/hindsight/` (10 файлов, mental-models.ts, seeds.json), `src/system/ttsr-*.md`.
- Порт в DSH: хуки на стриме (у DSH есть `assistant/message`?) + хранилище правил.
- Сложность: 🔴 высокая. Концепт уже описан в `agent-guards.ru.md` §9.

## 5. collab — многопользовательские live-сессии

- Суть omp: host-авторитетная топология, гости через relay, AES-256-GCM, зеркалирование
  событий/состояния, hub-чат/килл/ревью.
- Исходники: `src/collab/` (host.ts, guest.ts, protocol.ts, relay-client.ts, crypto.ts).
- Сложность: 🔴🔴 очень высокая (крипто, relay, репликация). Ниша.

## 6. autoresearch — A/B стенд промптов/моделей

- Суть omp: эксперименты над промптами и моделями с бейзлайнами, run-номером, дашбордом, resume.
  Исходники: `src/autoresearch/` (12 файлов + prompt.md, dashboard.ts).
- Сложность: 🔴 высокая. Отдельный инструмент, не тул.

## 7. Прочее сложное

- **browser** — Chromium + puppeteer из тула (вкладки живут между вызовами): 🔴 (безопасность).
- **computer** — управление рабочим столом (окна/скриншоты/AX): 🔴🔴.
- **ast_grep / ast_edit** — структурный поиск/правка по AST: 🟡-🔴 (плагин поверх бинаря).
- **hub** — супервизируемые долгие процессы (REPL/watcher): 🟡.
- **snapcompact** — снапшот-компакция контекста: 🔴 (меняет компакцию DSH).
- **autolearn** — авто-подъём SKILL.md из повторяющихся приёмов: 🟡 (связано с памятью).
- **stt/tts** — речевой стек на sherpa-onnx (ASR + TTS, русские модели): 🟡-🔴 — NaN

## Как отдавать сильным моделям

1. Дать модель/агент с доступом к: `/nix/store/.../omp-17.3.4/share/omp/src` (исходники),
   `/tmp/omo-repo` (omo), `docs/howto/designs/` (наши дизайны), этот файл.
1. На каждую фичу — отдельную задачу с критерием: работающий server-плагин в
   `modules/user/nix-maid/apps/dsh-<name>/` + nix-модуль + функциональный тест.
1. Проверять: node --check, nix parse, check-all-syntax, инъекция `inject` для сервисов.
1. Не забывать про инъекции (урок с ctx.tools/ctx.memory) и рестарт dsh для активации.
