# midi2sheet: MIDI → ноты в PDF

`midi2sheet` — CLI-инструмент (пакет `pkgs.neg.midi2sheet`), который превращает MIDI-файл в нотную
партитуру PDF для фортепиано: правая рука (≥ C4) — верхний стан, левая — нижний. Отрисовку делает
MuseScore Studio в headless-режиме (под Xvfb), поэтому команда работает без GUI и без открытого
дисплея.

## Использование

```bash
midi2sheet input.mid                    # -> input.pdf рядом с исходником
midi2sheet input.mid -o out.pdf         # явный путь вывода
midi2sheet input.mid --mscz             # дополнительно сохранить input.mscz (редактируемый исходник MuseScore)
midi2sheet input.mid --split 55         # порог разделения рук (MIDI-номер ноты, по умолчанию 60 = C4)
```

Название партитуры берётся из имени входного файла (без расширения). При запуске с `--mscz` рядом с
PDF появляется `.mscz` — его можно открыть и править в MuseScore.

## Как это работает

1. `split.py` (чистый Python, без зависимостей) разбирает MIDI (включая running status), делит ноты
   по порогу высоты на два трека и пишет format-1 MIDI с программой «Piano».
1. MuseScore импортирует разбитый MIDI (сам определяет размер/тональность, раскладывает по тактам,
   связывает длинные ноты лигами) и сохраняет `.mscz`.
1. `patch_title.py` переписывает `workTitle` в mscz (MuseScore берёт название из имени файла,
   отдельного CLI-флага нет).
1. Из исправленного mscz экспортируется финальный PDF.

MuseScore для пакета берётся из «чистого» `inputs.nixpkgs.legacyPackages` — глобальные оверлеи
конфига меняют хэш деривации `pkgs.musescore`, что привело бы к полной сборке из исходников; обычная
сборка уже лежит в store.

## Открыть/отредактировать mscz

```bash
nix shell nixpkgs#musescore -c musescore file.mscz
```

## Примечания

- Размер такта и тональность — это вывод MuseScore при импорте, а не данные из MIDI (в MIDI обычно
  стоит дефолтный 4/4). Если нужно другое — правьте в MuseScore.
- Квантизация: импорт MuseScore оставляет мелкую ритмику транскрипций (вплоть до 32-х/64-х); для
  «грязных» MIDI это читается тяжело — можно прогнать через `midi-transcribe --post quantize` до
  конвертации.
