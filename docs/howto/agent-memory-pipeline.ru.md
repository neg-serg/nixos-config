# Память: двухстадийный конвейер (порт из omp)

omp `prompts/memories/`: стадия 1 извлекает из «раскатки» сессии durable-знание, стадия 2
сливает его в долгую память + playbook'и-скиллы. Прямая аналогия с dsh-memento.

## Стадия 1 — извлечение (stage_one_system.md)

Строгий JSON, ничего кроме:

```json
{ "rollout_summary": "string", "rollout_slug": "string | null", "raw_memory": "string" }
```

- `rollout_summary`: компактный синопсис, который будущие запуски должны помнить.
- `rollout_slug`: короткий lowercase-slug (буквы/цифры/_), или null.
- `raw_memory`: детальные durable-блоки — достаточно контекста для переиспользования.
- Нет durable-сигнала → пустые строки и null. Шум отбрасывается, ничего не «на всякий случай».
- Держать: ограничения, решения, воркфлоу, подводные камни, разрешённые сбои.
- Выбрасывать: транзиентную болтовню, низкоинформативный шум.

## Стадия 2 — консолидация (consolidation.md)

Строгий JSON: `memory_md`, `memory_summary`, `skills[]`.

- `memory_md`: долгосрочный документ памяти.
- `memory_summary`: подсказка на промпт-тайме.
- `skills[]`: переиспользуемые playbook'и; каждый = `skills/<name>/SKILL.md`
  (+ опционально scripts/templates/examples). Устаревшее — удалять (prune),
  чтобы артефакты не копились.

## Правила чтения (read-path.md)

1. Сначала `memory_summary`.
2. Потом `MEMORY.md` и `skills/<name>/SKILL.md` по необходимости.
3. Память = эвристики и процессный контекст; текущее состояние репо, вывод рантайма
   и инструкция пользователя = факты/финальные решения.
4. Память противоречит репо/инструкции → память устарела; исправь поведение и обнови артефакт.
5. Уверенность — только после проверки в репо; память сама по себе НИКОГДА не доказательство.

## Маппинг на dsh-memento

- `memory_md` ≈ agent-track записи (workspace); `memory_summary` ≈ снапшот памяти сессии.
- `skills[]` ≈ SKILL-каталог DSH: повторяющиеся успешные приёмы сессий можно авто-поднимать
  в SKILL.md-плейбуки.
- Конвейер = два промпта (extractor/consolidator) + хуки завершения сессии;
  лимит бюджета memento — естественный ограничитель консолидации.
