# dsh-status-rotator — живой статус вместо «Deep diving...»

Плагин `dsh-status-rotator` (github:01Virex/dsh-status-rotator) заменяет
хардкод-строку **«Deep diving...»** — статус работающего агента в веб-интерфейсе
dsh (компонент `TurnStatus` в `dsh-client-ui-conversation`) — на ротацию фраз
с учётом фазы, эффектом печатной машинки и переливающимся градиентом.

## Что умеет

- **Три фазы**: `thinking` (0–15 с) → `running` (15–60 с) → `long` (после 60 с);
  переход фазы мгновенно меняет набор фраз.
- **Печатная машинка** (`typeSpeedMs`, 0 = выкл) и **градиент-перелив**
  (CSS `linear-gradient` + `animation`, `speed` = секунд на цикл).
- Конфиг отдаёт node-половина по `/plugins/dsh-status-rotator/config.json`
  (файл читается с диска на каждый запрос) — правки применяются по F5,
  рестарт dsh не нужен. Счётчик часов (появляется на 15-й секунде) плагин
  не трогает.

## Конфигурация

Файлы лежат в пакете плагина внутри web-профиля:

- `~/.dsh/profiles/web/node_modules/dsh-status-rotator/config.json` — рабочий
  конфиг (фразы, градиент, интервалы);
- `config.example.json` — фолбэк и источник для seed-шага.

Ключи: `intervalMs` (ротация, мс), `typeSpeedMs` (скорость машинки),
`longAfterMs` (порог фазы `long`), `gradient.{enabled,colors,speed}`,
`phrases.{zh,en}.{thinking,running,long}`. Язык фраз следует за UI-локалью dsh
(на этой машине — `en`), поэтому русские фразы лежат в группе `en`.

## Как это управляется в NixOS

Плагин входит в декларативный список ensure-скрипта `dsh-market.nix`
(модуль `modules/user/nix-maid/apps/dsh-market.nix`):

- **Установка** — `dsh plugin --profile web add github:01Virex/dsh-status-rotator`,
  если пакета нет в `package.json` профиля. Вокруг pnpm-операций симлинк
  `node_modules/@deepseek-ai` (указывающий на read-only nix store) «паркуется»
  в сторону: pnpm не может писать вложенные `node_modules` сквозь него
  (EROFS/ENOENT), а любая свежая установка перелинковывает дерево.
- **Seed** — `config.json` копируется из `config.example.json`, если пропал.
- **«neg look»-патч** — python-шаг приводит конфиг к принятому виду, заменяя
  **только стоковые значения**: радужный градиент → сдержанная палитра omp
  (`#005faf`, `#367CB0`, `#6C7E96`, `#287373`, `#5E468C`, `#914E89`, speed 6),
  английские мем-фразы → русские. Ручные правки `config.json` переживают
  пересборки — патч не срабатывает, если значения уже не стоковые.

То есть после любой переустановки плагина (pnpm-чистка, `dsh plugin update`,
маркет) внешний вид восстанавливается автоматически при следующем логине
или пересборке.

## Нюансы

- Правки конфига в `node_modules` переживают перезагрузку, но не
  переустановку пакета (pnpm удаляет каталог) — модуль вернёт палитру и фразы.
- Хочешь полностью свои фразы/цвета — редактируй `config.json`; управляемый
  патч их не перезапишет (он реагирует только на стоковые значения).
- Переустановка плагина до ближайшей пересборки откатит вид к стоковому —
  автоматика включится после `nh os switch`.
