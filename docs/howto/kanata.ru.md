# Kanata: раскладка CapsLock — статус и история

> Статус: **простая схема `CapsLock → Ctrl` (активна, стабильна)**. Caps-навигация (стрелки на
> `caps+hjkl` и алиасы Ctrl-комбинаций) **откачена и временно запрещена к применению** — см.
> «Решение» ниже.

## Текущее состояние (2026-08-20)

- Деплоится **простой** конфиг: `caps` → `lctl` (см. `files/cli/kanata/kanata.kbd`, деплой через
  `modules/user/nix-maid/sys/kanata.nix` → `~/.config/kanata/kanata.kbd`).
- Процесс: `kanata --cfg ~/.config/kanata/kanata.kbd` (systemd user service, см.
  `modules/hardware/input/default.nix`). Флаг фичи: `features.input.kanata.enable`.
- Применённый свитч генерации включает этот откат (коммит `6419062a`).

## История caps-nav (что пробовали и почему откатили)

Серия экспериментов с CapsLock-навигацией (стрелки `caps+hjkl`, `caps+space` = Tab, `caps+q` = Esc,
`caps+w` = F24, позже алиасы `caps+backspace` = Ctrl+H, `caps+delete` = Ctrl+K, `caps+enter` = Ctrl+J):

| Коммит | Что делал |
| ------ | --------- |
| `ad873820`, `487f8a8a` | CapsLock = Ctrl **и** мгновенный слой навигации (caps+hjkl → стрелки) |
| `a237ca77` | Time-split: быстрый `caps+key` = Ctrl+key, удержание >200ms = навигация |
| `499517b7` | «Instant caps-nav»: откат time-split (не давал надёжных стрелок), мгновенная навигация + алиасы Ctrl-комбинаций |

**Итог:** последняя версия (`499517b7`) **подтверждённо сломана** — при применении ломала ввод
(некорректные стрелки/модификаторы, сбитые Ctrl-комбинации). Поэтому:

## Решение (пользователь, 2026-08-20)

1. Caps-навигация **откачена** (коммит `6419062a`, простой `caps → Ctrl`) и пока **не применяется**.
2. Возвращаться к ней будем **отдельным экспериментом**, после завершения остальных задач —
   не «вплетать» в обычную работу и не применять впопыхах.
3. При любой работе с kanata — **внимательно**: сверить, что деплоится именно простая схема,
   проверить после свитча (`head ~/.config/kanata/kanata.kbd`, живой ввод), прежде чем закрывать задачу.

## Проверка после свитча

```bash
head ~/.config/kanata/kanata.kbd      # должно быть: (defsrc caps) / (deflayer base lctl)
pgrep -af 'kanata --cfg'               # процесс жив
systemctl --user is-active kanata.service
```

Если в дереве снова появились коммиты про caps-nav — свериться с этим документом перед сборкой:
по умолчанию они **не должны** попадать в деплой, пока не согласован отдельный эксперимент.
